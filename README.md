# BOOKSPHERE

Interactive frontend prototype for a fair author/reader marketplace.

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Included

- BOOKSPHERE landing experience
- Responsive discovery catalog
- First-pages preview modal
- Mobile-friendly layout
- Sample author/reader marketplace content

## Production roadmap

Connect authentication, PostgreSQL, secure object storage, server-side PDF/EPUB preview generation, Stripe/PayPal checkout, purchases/library, reviews, author payouts, and admin analytics. Never expose private book files or payment/API secrets in client-side code.
